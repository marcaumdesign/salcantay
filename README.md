# Salcantay Global

Landing page for Salcantay Global, built with [Next.js](https://nextjs.org).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it. Edit `app/page.tsx` to change the page.

## Build

```bash
npm run build
npm start
```

## Deploy

Deploys cleanly to [Vercel](https://vercel.com/new) with zero config.
